## Traps already hit (read before touching the pipeline)
- Never guess stats, roles or names. Unknown stays out and is listed for the owner.
- Cricsheet withholds Afghanistan matches (a protest since 2024-11-14) and has few ODIs before 2003.
- Cricsheet's names.csv has wrong aliases (Pat Cummins is also listed as "Anderson Cummins").
- Namesakes: HowSTAT pairing must pass `careerFits` (Iftikhar Ahmed once took Ijaz Ahmed's record).
- HowSTAT per-country rows are partial for players who also played for a World XI or another country.
- HowSTAT quirks: "2008-" = still playing; a printed 0 average can mean "no average"; one export had
  its header one column left of the data; Excel turned "Best" and "Born" cells into date numbers.
- HowSTAT's site is behind Cloudflare bot protection: do not scrape it.
- Shell: `git push` hangs on the Windows credential helper; use
  `git -c credential.helper= -c 'credential.helper=!gh auth git-credential' push`.
  Python edits passed through a Bash heredoc mangle `\n` and `\t`: write the script to `.test-dist/`
  with the Write tool, then run it.
- A stuck `npx astro check` once ran for 3 hours waiting on a prompt: don't run it unattended.
